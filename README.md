# Restoration PM Academy

Restoration PM Academy is a professional learning platform for restoration and construction project managers.

The academy is designed around a practical learning loop:

**Learn → Practice → Explain → Apply → Review → Master**

The curriculum is handcrafted, jobsite-focused, and vendor-neutral. AI supports the learner as an adaptive instructor by explaining concepts, coaching responses, and helping apply knowledge to real restoration conditions.

## Product direction

Initial capabilities will include:

- Structured restoration curriculum and lessons
- Scenario-based quizzes
- XP, mastery, and progress tracking
- Daily review and spaced repetition
- Jobsite-oriented learning experiences

Future capabilities may include voice instruction, photo-assisted inspections, field notes, PM simulations, drawing interpretation, proposal review, report writing, and estimating practice.

## Technology

The initial web application will use Next.js, React, TypeScript, Tailwind CSS, and the Next.js App Router. Supabase and Vercel are planned for authentication, data, and deployment.

## Status

The project is in active foundation development.
